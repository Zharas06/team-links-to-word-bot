# Telegram-бот для сбора ссылок и автоматического отчёта в Word

Бот автоматизирует ежедневную отчётность отдела по информационной работе.
Раньше сотрудники присылали ссылки на публикации вручную, а отчёт собирался в Word по таблицам.
Теперь каждый сотрудник отправляет ссылки боту, а администратор одной кнопкой получает готовый Word-отчёт за нужную дату.

*Telegram bot that collects publication links from a team and generates a daily Word report from a template.*

## Возможности

- **Доступ по кодам** — сотрудники входят через `/join код`, администратор через `/admin код`. Коды задаются при запуске и нигде не хранятся в файлах.
- **Три раздела** — видео, инфографика, экспертное мнение.
- **Темы из шаблона** — список тем бот берёт из заголовков таблиц в `template.docx`, поэтому темы меняются без правки кода.
- **Приём ссылок** — можно отправить несколько ссылок одним сообщением, повторы отсекаются автоматически.
- **Выбор даты** — ссылки можно привязать к любой дате публикации.
- **Мои ссылки и удаление** — сотрудник видит свои последние записи и может удалить ошибочную через `/delete номер`.
- **Отчёт в Word** — администратор выбирает дату и получает `.docx`: дата подставляется в шапку, ссылки расставляются по таблицам и темам в виде кликабельных гиперссылок.

## Безопасность

- Токен бота и коды доступа вводятся при запуске со скрытым вводом (`getpass`) и не сохраняются в коде.
- Логи сторонних библиотек отключены, чтобы токен не попал в терминал.
- Бот работает только в личных сообщениях.

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python bot.py
```

При запуске бот попросит токен от @BotFather и два кода: для сотрудников и для администратора (разные, минимум 8 символов).
База `links.sqlite3` создаётся автоматически.

## Шаблон отчёта

`template.docx` в репозитории — демонстрационный, с темами «Тема 1…9».
Требования к своему шаблону:

- ровно три таблицы (видео, инфографика, экспертное мнение);
- в каждой таблице первая колонка «№» и девять колонок с темами;
- названия тем во всех трёх таблицах совпадают;
- дата в шапке в формате ДД.ММ.ГГГГ — бот заменит её на дату отчёта.

## Технологии

Python 3, python-telegram-bot 22, python-docx, SQLite.
